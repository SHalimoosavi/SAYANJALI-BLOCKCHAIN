POST-VALIDATION CORRECTIVE PATCH
- Block construction now materializes a missing transaction hash using the existing frozen Transaction.ComputeHash() algorithm. This fixes propagation/storage round-trip of newly constructed coinbase transactions without changing the hash algorithm or serialization.
- P2P network startup now derives a reachable 127.0.0.1 advertised endpoint when the listener is configured with an unspecified address and no explicit advertised address. Explicit production advertised addresses remain authoritative.
- Regression tests cover both behaviors.

POST-VALIDATION CORRECTIVE PATCH 02
- Peer cleanup is session-aware so an old duplicate connection cannot delete a newer live peer entry; this stabilizes simultaneous inbound/outbound seed dialing and peer counts.
- Difficulty selection retains the previous difficulty until the frozen 10-block retarget window exists and invokes retarget only at the corresponding epoch boundary. Frozen consensus code/vectors are unchanged.
- Node lifecycle now exposes Done(); syjd start exits when Node.Stop is triggered by the API shutdown endpoint, preventing stale long-lived processes after stop.
- Removed an unused transaction JSON marshal from Node.SubmitTransaction.
